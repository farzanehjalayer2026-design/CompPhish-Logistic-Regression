CompPhish Phishing Website Detection with Logistic Regression. This repository contains the code, selected data, and evaluation results for a binary classification experiment based on the CompPhish phishing website dataset. A balanced subset of 1,000 records was used, with 500 phishing and 500 legitimate websites, sampled with a fixed random seed for reproducibility. Feature selection was performed using coefficient magnitude from a logistic regression model, focusing on the top 20 features out of the original 68. Five-fold cross-validation showed a trade-off between model simplicity and performance.
